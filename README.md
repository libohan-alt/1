# 英语王：雾村

一个无需安装依赖的静态英语学习冒险。英语王来到被寒雾笼罩的村庄，与村民交谈并挑战三位知识之主；游戏复用现有语法题库，进度保存在当前浏览器。

## 运行

建议使用本地 HTTP 服务打开：

```powershell
cd d:\1\proojects\untitled1\1
py -m http.server 8000
```

访问 <http://localhost:8000/>。停止服务时在 PowerShell 按 `Ctrl+C`。

## 剧情与玩法

1. 开始时输入姓氏；结局会将姓氏刻在石碑上。
2. 在村庄里走近村民交谈，依次选择三位知识之主进行单体挑战。击败三位后，他们将不甘心地卷土重来，解锁三位 boss 同时登场的综合挑战。
3. 每局知识点从 0 开始。按 `Q` 原地答题，答对 `+1`、答错 `-1`；答题可无限继续，直到选择返回。知识点无上限；任何操作导致知识点为负时立即失败，知识点不足以移动或挥剑也会失败。
4. 每移动一格消耗 1 点；每次挥剑也消耗 1 点。剑弧由玩家位置逐渐扩展至前方两格，命中弧内敌人时造成 1 点伤害。boss 需要命中 20 次击败；小怪需要命中 10 次后消失。
5. boss 会蓄力挥出可见的两格红色剑弧，弧形完成时若命中玩家，普通攻击扣 5 点；每第十次命中发动大招、扣 20 点并召唤小怪。小怪每次攻击扣 1 点。敌人攻击令知识点降到 0，或知识点不足以移动/挥剑时，本局失败。
6. 村庄与战场的建筑会影响策略：村庄守夜祠可为下一场战斗储存 3 点护盾；战场遗迹旁带符号的地砖各可触发一次效果，`+` 恢复 2 点知识，`◇` 抵消下一次受击的 3 点伤害，`!` 使下一次受击额外损失 2 点知识。迷宫另有陷阱和传送门；镜头随英语王移动，初始四格视距之外被迷雾遮蔽，每击败一位单体 boss，视野扩大 0.75 格。踩中陷阱会扣 2 点知识。敌人会寻路、避开陷阱，并尝试躲开玩家剑弧。胜利或主动离开战场时，展示本局已答题目的答案与解析。完成综合挑战后播放结局。

**操作：**方向键或 `WASD` 移动；长按方向键可加速连续移动（战斗中每格仍消耗 1 点）；`E` 与村民交谈；`Q` 答题并用数字键 `1`–`4` 选择；`Space` 朝面向方向挥剑；`F1` 或 `?` 随时打开 Markdown 游戏说明，按 `Esc` 关闭。手机/平板可按住屏幕方向键连续移动，并使用动作按钮操作；界面适配安全区与窄屏尺寸。

使用“重新开始”会清除姓氏和通关记录。浏览器存储不可用时，当前页面仍可继续，但无法持久保存进度。

## 自由练习

首页“练习”菜单保留原有独立测验；综合练习需先在剧情中分别击败三位 boss：

| 页面 | 内容 | 题库类别 |
| --- | --- | --- |
| `two.html` | Already / Just / Yet | `c1` |
| `three.html` | For / Since | `c2` |
| `four.html` | Have been / Gone to | `c3` |
| `five.html` | 综合练习，限时 60 秒 | `all` |

专项练习默认每轮 10 题。答案解析在本轮结束后统一呈现；综合练习超时后，未答题目会标记为“未作答”。

## JavaScript 文件

- `engine.js`：通用题目生成、选项构造与洗牌算法。
- `data.js`：语法题目素材、规则与 `TOKENS` 题库。
- `game.js`：诗性村庄故事、建筑地图与战斗、对话、答题、存档与键盘/触屏控制。
- `game.css`：游戏界面视觉与响应式样式；冒险地图铺满视口，状态与自由练习收在浮动菜单中，大字号优先使用华文行楷，小字号优先使用楷体或 Noto。
- `quiz-ui.js`、`quiz-mini.js`、`quiz.css`：独立自由练习页面的渲染、流程与样式。
- `app.js`：未接入页面的旧版完整界面，保留作历史实现。

## 安全与隐私

这是一个本地静态学习工具，不包含服务端或账号系统。姓氏和通关状态只保存在浏览器 `localStorage`；对话、题目和姓氏均以文本方式展示，不作为 HTML 执行。不要将密码、API 密钥或其他凭据写入 HTML、JavaScript 或题库。
